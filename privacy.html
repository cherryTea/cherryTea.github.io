Privacy Policy

Last updated: October 12, 2026

This application is a personal OAuth client used only by its owner to access their own Google Drive with rclone. It is not offered to, or intended for, anyone else.

Data accessed

With the owner's permission, the application accesses files and metadata in the owner's Google Drive. This is only done to sync files between the owner's own computer and Google Drive.

Data storage

OAuth tokens are stored only on the owner's computer, in the local rclone configuration file. Files are moved directly between Google Drive and that computer. No data is sent to, or stored on, any other server.

Data sharing

No data is sold, shared or passed to third parties. No data is used for advertising, analytics or AI/ML training.

Google API Services

This application's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions can be raised as an issue on the GitHub repository that hosts this page.
